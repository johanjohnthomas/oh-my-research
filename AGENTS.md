# Oh My Research — Repository Guide

## Current Identity

This repository is being remade into a local-first research workflow for producing evidence-backed scientific papers in LaTeX.

## Current Source of Truth

The most important current artifacts are:

- `.sisyphus/plans/research-first-remake.md`
- `.sisyphus/evidence/`
- `README.md`
- `docs/reference/cli.md`
- `docs/guide/installation.md`

## Current Architecture Direction

The remake centers on:

- canonical `.research/` artifacts
- Zotero-only bibliography authority
- staged research workflow execution
- manuscript generation and verification
- first-class local Obsidian export
- first-class local derived knowledge graph output

## Transition Note

Some host-adapter and compatibility code from the original agent harness still exists in `src/`. Those areas are under active extraction and should not be treated as the long-term product story for this repository.
